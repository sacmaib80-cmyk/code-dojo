# Code Dojo

**A 157-exercise coding drill site I built to tutor my classmates before an exam.**

Our class had a programming exam coming and most people didn't know where to start. Rather than
explain the same things one at a time, I built the drills into a site and used it to teach from.

![Home](screens/dojo-home.png)

## What's interesting in here

- **157 exercises across 18 stages**, ordered so each one only needs what the previous stage taught.
- **Stages stay locked until you clear 70% of the one before.** The point isn't difficulty — it's
  that people skip fundamentals and then fail on them later, so the site won't let you.
- **It tells you why you were wrong, not just that you were wrong.** Hints are written to push you
  one step, not to hand over the answer.
- **XP and ranks**, because the people using it were classmates who wanted to see they were moving.
- Ships as a single self-contained HTML file — no install, no server, works from a USB stick.

## Stack

Single-file HTML / CSS / JavaScript · no dependencies · no build step

## Honest notes

Built for real tutoring sessions, not as a demo. **It has no usage analytics**, so I can't tell you
how many people finished it — I know it was used because I taught with it and classmates told me
they'd gone through exercises. Writing it without any measurement is the reason the next project I
built shipped with usage tracking from the start.
